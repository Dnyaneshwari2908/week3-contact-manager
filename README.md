# Contact Management System

## Project Description

This project is a Contact Management System developed using Python.

It allows users to:
- Add contacts
- Search contacts
- Update contacts
- Delete contacts
- View all contacts
- Export contacts to CSV
- View contact statistics

---

## Features

- Uses dictionaries for contact storage
- Uses functions for modular programming
- Validates phone numbers
- Uses JSON file handling
- Supports partial search
- Exports contacts to CSV
- Handles invalid inputs

- Python
